# Study with Love 2.1

Обновления интерфейса:
- Удалён пункт «Повторить темы» с главного экрана.
- Добавлен экран «Мой прогресс» с общим процентом, процентом по разделам и каждой теме.
- Для каждой темы можно сохранять этапы 25%, 50%, 75% и 100%.
- После отметки «Я позанималась сегодня» приложение остаётся на странице темы, а не возвращает на главный экран.
- Добавлены мягкие анимации появления экранов.
- Обновлена конфигурация адаптивной иконки приложения; версия приложения повышена до 2.1 (versionCode 3).

Сборка: GitHub → Actions → Build Study with Love APK → Run workflow.
Артефакт: Study-with-Love-APK.

# Study with Love 2.0 — облачная сборка APK

Обновление приложения для одного телефона, без сервера и без обязательного интернета.

## Что нового в версии 2.0
- Счётчик дней занятий подряд и личный рекорд серии.
- День засчитывается при нажатии «Я позанималась»; повторное нажатие в тот же день не увеличивает серию.
- Настройка дней недели и нескольких времён напоминаний.
- Напоминания планируются по часовому поясу Asia/Baku и восстанавливаются после перезагрузки телефона.
- Новая розовая иконка с цветком и сердцем.

## Сборка через GitHub Actions
1. Распакуйте архив.
2. Откройте папку `study_with_love`.
3. Загрузите **содержимое** этой папки в корень своего GitHub-репозитория, сохраняя структуру каталогов. Подтвердите замену существующих файлов.
4. Убедитесь, что в репозитории есть `.github/workflows/build-apk.yml`.
5. Откройте Actions и запустите `Build Study with Love APK`.
6. После успешной сборки скачайте артефакт `Study-with-Love-APK`; внутри ZIP будет `app-debug.apk`.

## Установка обновления
Установите APK на Android. Если система сообщает о конфликте подписи с предыдущей тестовой сборкой, удалите предыдущую версию и установите новую. Удаление приложения стирает его локальные данные, поэтому сначала убедитесь, что нужный прогресс не требуется сохранить.

## Важно про уведомления
- На Android 13 и новее разрешите приложению отправлять уведомления при первом запуске.
- Проверьте, что уведомления приложения не запрещены в настройках Android.
- Некоторые производители ограничивают фоновые уведомления режимом энергосбережения; при задержках разрешите автозапуск/работу в фоне для Study with Love.

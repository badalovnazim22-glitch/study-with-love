# Study with Love 2.0

Личное офлайн-приложение для занятий математикой. Сервер не требуется.

Функции: четыре раздела математики, отметки тем, прогресс, серия дней занятий и рекорд, настраиваемые напоминания по дням недели и времени (Asia/Baku), уведомления после закрытия приложения и новая иконка.

Сборка выполняется через GitHub Actions. Подробная инструкция — `README_CLOUD_BUILD_RU.md`.

# Study with Love — Android-приложение

Это самостоятельный Android-проект на Java. Приложение работает без Telegram и не требует интернета для основных функций.

## Что уже реализовано
- Розовый интерфейс и главное меню.
- 4 раздела и все темы из исходного Python-бота.
- Выбор темы и экран инструкции к занятию.
- Отметка выполненной темы и сохранение прогресса на телефоне.
- Случайные мотивационные послания.
- Ежедневные уведомления в 10:00, 15:00, 19:00 и 21:00 по часовому поясу Asia/Baku.
- Повторная установка напоминаний после перезагрузки телефона.

## Как получить APK
1. Установить Android Studio на компьютер.
2. Открыть в Android Studio папку `study_with_love` (папку, в которой находится `settings.gradle`).
3. Дождаться загрузки Android Gradle Plugin и Android SDK (для первой сборки нужен интернет).
4. Выбрать **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Примечания
- Для Android 13 и новее нужно разрешить уведомления при первом запуске.
- Напоминания запланированы по времени Баку и работают через системные уведомления Android. Производитель телефона может ограничивать фоновые уведомления настройками энергосбережения.
- Приложение не содержит сетевых запросов и не отправляет данные куда-либо.
- Для установки APK, собранного для личного использования, на телефоне может потребоваться разрешить установку приложений из выбранного источника.

# Как получить APK без Android Studio

В проект добавлен GitHub Actions workflow `.github/workflows/build-apk.yml`. Он собирает APK на облачном сервере GitHub.

1. Создайте аккаунт на https://github.com/ (если его ещё нет).
2. Создайте новый репозиторий, например `study-with-love`. Для личного приложения лучше выбрать **Private**.
3. Загрузите в корень репозитория содержимое этой папки проекта: `settings.gradle`, `build.gradle`, `gradle.properties`, папку `app` и папку `.github`.
4. Откройте вкладку **Actions** в репозитории. Если GitHub попросит разрешить Actions, подтвердите.
5. После загрузки файлов сборка обычно стартует автоматически. Если нет: **Actions → Build Study with Love APK → Run workflow**.
6. Дождитесь зелёной отметки успешной сборки. Откройте запуск workflow и внизу раздел **Artifacts**.
7. Скачайте `Study-with-Love-APK.zip`, распакуйте его и получите `app-debug.apk`.
8. Передайте `app-debug.apk` на Android-телефон и установите. При запросе Android разрешите установку из этого источника.

Важно: APK пока debug-сборка для личной установки, не публикационный релиз Google Play. GitHub Actions предоставляет бесплатные минуты для публичных репозиториев; лимиты для приватных репозиториев зависят от тарифного плана аккаунта.
